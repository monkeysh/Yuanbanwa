# 原版娃口语 · 跟读示范录音脚本

> 嗨 阿黛老师 / 小何老师 🌿 感谢帮忙。一共 **8 段，63 句**，每人 **10–15 分钟**能录完。

## 🎙️ 录音方法

1. **iPhone 语音备忘录** 就够用（设置 → 音频质量 → **无损**）
2. **每段录一个文件**，一共 8 个
3. 命名：`<名字>_<场景 ID>.m4a`（见每段标题）
   - 阿黛：`adai_starbucks.m4a` / `adai_restaurant.m4a` …
   - 小何：`xiaohe_starbucks.m4a` / `xiaohe_restaurant.m4a` …
4. **句子之间停 1.5 秒** —— 方便自动切片
5. **读错就重念一遍**，不用剪
6. **语速自然**，不刻意放慢，像跟朋友说话
