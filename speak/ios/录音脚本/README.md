## 为什么要录这些

我们做了一款「零门槛场景跟读」APP：用户每天花 5 分钟，跟着老师念几句真实场景英文（星巴克点单、机场值机、酒店入住这类）。我们希望：

- **阿黛老师**录**美式发音**版本
- **小何老师**录**英式发音**版本
- 用户可以在 APP 里自由切换想跟的口音

---

## 录音要求

1. **环境**：安静、无回音的房间。关窗、空调尽量小。
2. **设备**：iPhone 自带的「**语音备忘录**」App 就够了 —— 记得在设置里把**音频质量**调到「**无损**」。
3. **每个场景录一个文件**，一共 **8 个文件**。命名约定：
   ```
   adai_<场景拼音>.m4a    （阿黛用）
   xiaohe_<场景拼音>.m4a  （小何用）
   ```
   具体场景 ID 写在下面每一节的标题里。
4. **语速自然**，像跟朋友说话一样。**不要刻意放慢**。
5. **句子之间停 1.5 秒左右** —— 这样我能自动切片。
6. **读错了怎么办**：再念一遍就行，不用剪。比如念错了第 3 句，直接「第 3 句，<正确版本>」重念，我后期筛掉。
7. **情绪轻松自然** —— 不要念广播腔，像真实对话就好。
