# Speak 学习数据板块设计 · 2026-07-31

> 背景:全网竞争力评估结论——跟读拼量拼不过大厂,Speak 的稀缺资产是 ①腾讯 SOE 音素级真实发音分 ②模拟考官 ③主站 300+ 学员信任。学习数据板块是把 ① 变成可见价值的载体,也是家长续费理由的直接来源。

## 一句话定位

**别人给"今天练了多少句",我们给"发音进步了多少、具体哪个音不准"。**
SOE 每句返回 总分/准确度/流利度/完整度 + 逐词 + 音素级准确率——这是真人老师都难以系统给出的诊断,目前练完即丢。本板块第一件事就是把它留下来。

## 现状(2026-07-31 实测)

| 项 | 现状 |
|---|---|
| 持久化 | iOS `AppStore` → UserDefaults:`sceneProgress`(%)、`streakDays`、`totalSentencesPracticed`、`completedSceneIds`、`reviewQueue`。**无 session 明细、无任何分数留存** |
| SOE 分数 | `PracticeScreen.applyScore(_:)`(约705行)拿到 `ScoreResult`(含 `SOEDetail`:accuracy/fluency/completion + words[].phones[]),仅用于当句 UI 和 weakIndexes,随后丢弃 |
| 考官 | `ExamScreen` 有 SOE 引用,但轮次/表现不落盘 |
| 账号 | `AuthManager` 是 **mock**(本地假 OTP、mock token、管理员 001/218 硬编码),无真后端身份 |
| web | localStorage `ybw.speak.progress.v1`,20 分钟公开体验,无账号 |
| UI | 4 tab(首页/场景馆/复练/我的);MeScreen 已有 streak 植物卡、已练句数、近 4 周热力格 |

## 读者与出口

- **孩子**(练习者):App 内成长页——激励 + 弱项闭环到复练。
- **家长**(买单者):周报分享卡——价值证明,微信转发即天然口碑。
- 两个出口共用同一份数据,不做两套。

## 分期(P0 不碰账号/后端,立即可做)

- **P0 · iOS 纯本地**:S1 数据记录层 → S2 成长页 → S3 发音体检 → S4 家长分享卡 → S5 考官记录。全部本地,真机可验,不依赖任何后端决策。
- **P1 · web 引流钩子**(可选,一行文案):web ResultScreen 尾部"完整发音体检报告在 App"。
- **P2 · 云同步 + 真账号**(需拍板,本文档只留接口):见文末"待拍板"。

## P0 设计

### S1 数据记录层(核心)

新文件 `Speak/Models/PracticeLog.swift`:

```swift
struct WeakWord: Codable { let word: String; let score: Int }        // <65 分词
struct PhoneStat: Codable { let phone: String; let sumAcc: Double; let count: Int }

struct PracticeSession: Codable, Identifiable {
    let id: UUID
    let day: String            // "yyyy-MM-dd" 设备本地日(吸取主站 progress.ts UTC 事故)
    let startedAt: Date
    let sceneId: String
    let tierLevel: String
    let mode: String           // "practice" | "review" | "exam"
    let sentenceCount: Int     // 练习句数(含未评分句)
    let scoredCount: Int       // 真实 SOE 评分句数
    let avgOverall: Int?       // scoredCount == 0 → nil,绝不填假分
    let avgAccuracy: Int?
    let avgFluency: Int?
    let avgCompletion: Int?
    let weakWords: [WeakWord]
    let phoneStats: [PhoneStat]   // session 内音素聚合(体检的原料)
    let durationSec: Int
}
```

存储:`Documents/practice_log.v1.json`
`{ "schemaVersion": 1, "sessions": [...], "monthlyRollup": {...} }`

- **为什么不 SwiftData**:引入+迁移成本高;千条 JSON 读写毫秒级;单文件天然可导出,P2 云同步=上传这个文件。
- **为什么不 UserDefaults**:大 payload 不该进 defaults(现有小聚合字段原样保留,兼容)。
- **封顶**:保留最近 365 天且 ≤1000 条;超限的最老 session 折进 `monthlyRollup`(月份 → 天数/句数/平均分/音素聚合),明细丢、聚合不丢。
- **挂点**:`PracticeScreen` 在 `applyScore` 处累积逐句 `ScoreResult`,`recordPractice` 时由 `AppStore` 扩展方法 `logSession(...)` 一并落盘。ExamScreen 结束时同样落一条 `mode:"exam"`。

**口径铁律(继承产品红线)**
1. **假分红线**:Web Speech / 降级 / 未评分句永不进分数统计;`scoredCount==0` 的 session 所有 avg 为 nil,UI 显示"未评分",绝不显示 0 分或编分。
2. "天"一律设备本地日。
3. 迁移幂等:上线日起记,**不回填不伪造历史**;旧聚合字段继续累加,两套并存不打架。
4. `schemaVersion` 门:未知版本只读不写,防降级 App 毁文件。

### S2 成长页(重构 MeScreen,不加 tab)

自上而下(减法原则,全部只读、无强制交互):

1. **本周速览 4 格**:练习天数 / 句数 / 平均发音分(± 对比上周) / 连续打卡(合并现有 streak 植物卡)
2. **发音趋势**:近 14 天平均 overall,手绘 Capsule 柱(不引 Charts 依赖,iOS16 兼容);无评分日为空柱
3. **发音体检**(差异化主打,见 S3)
4. **场景地图**:daily 15 厚场景 + KET18/PET12/FCE12 网格,完成盖章(主站单元巩固地图的口语简化版)
5. **模拟考官记录**:最近 5 轮(考试/话题/日期/轮数)
6. **「本周报告」按钮** → S4 分享卡

现有"近 4 周热力格"保留,并入趋势区。外观/口音设置沉底。

### S3 发音体检(全网跟读产品没有的东西)

- 全期 `phoneStats` 聚合 → 弱音素 Top5(count≥8 才入榜,防小样本误诊)
- 每条展示:**音标 + 中文名称与要领一句话 + 你的准确率 + 你的弱词举例 2-3 个**
  例:`/θ/ · th 咬舌清音(舌尖轻触上齿) · 准确率 54% · think、birthday`
- 点击 → 组一次"含该音素弱词"的定向复练(复用现有 ReviewScreen 通道,`filteredIndexes` 已支持)
- 需人工资产:**英语音素中文映射表**(~48 条,Claude 出初稿 → 你/多AI 终审教学表述)

### S4 家长周报分享卡

- `UIGraphicsImageRenderer` 纯手绘 1080×1350(4:5),零依赖(对齐主站 GrowthShareCard 的 Canvas 手绘路线)
- 内容:昵称 + 本周天数/句数/平均发音分 + 进步最大 3 词(本周分 − 上周分)+ 弱音提示 1 条 + 品牌落款「原版娃口语」
- **铁律:无二维码、无价格、无邀请返利**(违反 App Store 3.1.1 + 既定分享物料规范)
- 出口:系统分享面板(存相册/发微信)

### S5 考官记录

`ExamSession` 并入同一日志文件(`mode:"exam"` + `examMeta:{exam, topic, questions}`)。评分维度考官侧暂无 → 只记轮次与完成,分数字段留 nil,不造假分。

## 风险与坑

- 存储膨胀:phoneStats 只存聚合(sum/count),单 session <2KB,千条 <2MB,封顶兜底。
- 老版本 App 读新文件:schemaVersion 门 + 全 Optional 解码。
- 音素样本偏差:count 阈值 + 只展示 Top5,避免"练得少=诊断错"。
- xcodegen:S1 新增 Swift 文件后 `rm -rf build` 全量重建(铁律)。
