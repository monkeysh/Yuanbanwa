## P0 已完成

### 评分、结果与练习状态

- 删除固定 92 分、固定连续天数和固定结果；结果页读取真实 `SessionResult`。
- Web Speech 成功时展示目标词识别的“词句完整度”；降级、拒绝权限或未识别时明确显示“本句未评分”，不再生成假分。
- `matchWords` 会消费已匹配 token，重复词不能复用同一次识别结果。
- `phase` 与 `playback` 分离；录音/分析时禁止播放示范，离页停止音频，`Audio.play()` 拒绝后 UI 可恢复。
- 详情页预览播放按钮接入真实音频，不再是空按钮。

### 进度与复练

- 首次复练队列为空，不再注入演示错句。
- 复练只移除“实际完成评分且通过”的句子；漏词或未评分句继续保留。
- 场景卡和 Cambridge 完成度使用句级真实进度。
- 所有复练引用均使用 `{ sceneId, tierLevel, sentenceId }`。

### 体验身份与隐私

- 删除伪手机号、任意验证码和硬编码超管入口，改成明确的 20 分钟本地公开体验。
- 昵称可选，仅存当前浏览器；页面启动即清理可能包含旧手机号的 `ybw.speak.auth.v1`。
- 补齐真实 `terms.html` / `privacy.html`，说明 localStorage、Web Speech 第三方系统处理边界和删除方式。
- “我的”页硬编码偏好入口改成明确的体验说明，不再伪装成可点击设置。

### 发布与 SOE 安全

- `deploy-speak.sh` 改成“先构建、再严格白名单同步 `dist/`”，默认远端快照并保留 dry-run。
- 生产不再依赖 unpkg 或浏览器 Babel；React / ReactDOM 和 app bundle 都自托管、哈希化。
- `ops/speak-soe/` 增加 HMAC、防重放、限流、并发、输入限制、精确 CORS、超时、非 root PM2、nginx 与测试。
- SOE 文档同时持久化 root 与 `speak-soe` 用户的 PM2 dump，避免重启复活旧 root 进程。

## P1 已完成的基础

### 稳定句子身份

- `scenes.json` 的 724 条 tier 句子都有全局唯一的显式 ID，并保留旧位置 ID 的 `legacyIds`。
- `transformScenesJSON()` 对缺失 ID 直接报错，不再静默按数组位置生成。
- `scripts/validate_site.mjs` 会阻止缺失/重复 ID、无效 legacy ID 和坏引用进入构建。
- `splice_cambridge_new.mjs` / `splice_ket_new.mjs` 会为后续新增内容生成显式 ID；不要手工重新编号旧 ID。

- 升级后新增句子不会因为旧 `scenesDone` 在每次读取时被自动判完成。

## Claude 下一步建议（P1）

按此顺序继续，避免同时动内容、存储和生产服务：

1. 在用户明确允许麦克风的真机 Safari / Chrome 做一次 Web Speech 成功、拒绝、网络失败三路径回归；不要保存测试语音。
2. 为详情页预览音频补播放中/失败的可视状态与按钮可访问性回归。
3. 把 `index.html` 的中央状态继续拆分为小模块或引入正式 Vite 源码结构；迁移时保持 `npm run validate` 先绿，不要一次性重写整个应用。
4. 补浏览器级自动化：公开体验、daily/Cambridge 路由、空复练、完成结果、复练保留、旧进度迁移。
5. 若要正式账号/付费/云同步，先设计服务端认证与数据模型，再替换本地体验；不要把验证码或权限判断放回静态前端。
6. SOE 只有在签名调用方先上线且端到端 401/429/200/重放测试通过后才能切换。
