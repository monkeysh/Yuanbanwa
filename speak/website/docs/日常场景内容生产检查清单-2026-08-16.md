# 日常场景内容生产检查清单

> 来源:批次A(8个生活刚需场景补档)四轮 AI 审核暴露的系统性错误。**每一轮都抓到新问题,包括修复时引入的新矛盾**。写新内容前先过一遍这份清单,能省掉大部分返工。
>
> 适用:`_content-drafts/daily-deepen-*.json` 的写作与审核。

## 一、产品形态(不要审偏)

- 日常场景是**台词表**:只写学员自己要说的话,**不含对方台词**。这是用户 2026-08-16 明确拍板的产品选择。审核 prompt 里必须写明,否则 AI 会一直建议"加上对方的回应"。
- AI 自由对话只给剑桥备考场景,日常场景**不开放**(`SceneDetailScreen` 里 `if isCambridge` 是有意为之)。
- 档位规格对齐 `restaurant`:**entry 4 / beginner 9-10 / intermediate 9 / advanced 11**。
- 补档时**现有 beginner 档一字不动**——ID 与音频都不动,老用户进度不受影响,音频零重烧。

## 二、四类反复犯的错(按代价排序)

### ① 安全与责任(代价最高)
学员英语不好,会照着念。任何可能让人**延误必要处置**或**置身风险**的内容都是必改:
- 医疗急症被轻描淡写。批次A 原稿写了"右下腹锐痛 7 分 + 无法进食"(疑似急腹症),开场却说"我在判断是该去急诊还是**可以再等等**"——错误淡化风险。
- 把**问价格排在必要检查之前**,可能暗示因费用拖延就医。问费用必须限定前提:`If this isn't an emergency, could you tell me...`
- 人身安全:住宅可能有入侵者时,不能写"进屋清点损失"、不能写"自己去对质"。
- 该打 911 的情境要写出来(独自一人头晕不能开车、犯罪可能正在发生)。

### ② 事实与本地流程(第二高)
**不要凭想象写美国/领事流程**,写了就会错。批次A 踩过的:
- 中国护照在美补办:走**「中国领事」APP** 提交,**不以警方报告为前置**,**没有**普遍适用的付费加急;16 岁以上原则上需**到馆采指纹**;急需回国走**旅行证**。
- LAPD:用 **DR number / incident number**(不是泛泛的 case number);现场先给报案编号,**正式报告需另行申请**;**住宅入室盗窃不能网上报案**,正在发生的犯罪必须打 911;车内盗窃(theft from vehicle)在无嫌疑人、无人受伤时**可以**网上报案。
- 医疗:`take my insurance` ≠ `in network`,两者要分开写;常规洗牙**不需要** referral/prior authorization(那是专科转诊或复杂治疗才有);提前配药走 **vacation override**。
- 零售:美国标价**通常不含税**;`final sale` 决定能否退换;`price adjustment` 与 `store credit` 是两回事。

### ③ 内部一致性(最容易在"修复时"引入)
**这是批次A 最大的教训**:第一轮按建议加了一句"我还没进屋"的安全提示,却没检查它和后面句子的关系,结果第三轮才发现:
```
#3 我还没进屋,不知道里面有没有人
#4 我的笔记本和现金不见了        ← 没进屋怎么清点的?
#5 这个能网上报案吗?             ← 疑犯可能还在屋里
```
**改动一句之后,必须重读整档**,检查:
- 时间线矛盾(没进屋却清点损失、药已配好却说等你配好)
- 情境跳变(对警察说着说着变成对领事馆说)
- 顺序不合理(先道谢再提问)

### ④ 与已有档位重复(量最大)
批次A entry 档一次被抓出 19 处重复。根因:写 entry 时想"最核心的句子",而 beginner 档也是核心句,天然撞车。
- **entry 不是 beginner 的简化版**,而是**不同的核心动作**。
  - ✗ `How much does this cost?`(初级已有"how much is this")
  - ✓ `Could you scan this for me?` / `Is there a cheaper option?`
- 写完必跑字面重复自检(见下)。

## 三、写作要点

- **美式英语**:pharmacy/drugstore、line(不是 queue)、coworker(不是 colleague)、check(餐厅账单)、cell phone。
- **advanced 要"更深"不是"更长"**:覆盖复杂情况、需要周旋交涉(保险拒付、催单升级、改期费减免、证据保全),而不是把句子写长、词换难。
- **对中国学员的刚需别忘**:`Is there anyone available who speaks Mandarin?` / `Could I have a Mandarin interpreter, please?` —— 医疗、警务、政府柜台都该有。
- 每句要能**一口气跟读完**,别写绕口或超长的句子。

## 四、上线前自检(可直接跑)

```bash
# 档位规格 + 与已有档字面重复
python3 - <<'EOF'
import json
R='/Users/gelili/Documents/Claude.English/Speak-website/'
c=json.load(open(R+'_content-drafts/daily-deepen-batchA.json',encoding='utf8'))
sc={s['id']:s for s in json.load(open(R+'scenes.json',encoding='utf8'))['scenes']}
for tid,t in c.items():
    if tid.startswith('_'): continue
    assert (len(t['entry']),len(t['intermediate']),len(t['advanced']))==(4,9,11), tid
    ex={x['en'].lower().strip('.,?! ') for x in sc[tid]['tiers'][0]['sentences']}
    for lv in ('entry','intermediate','advanced'):
        for s in t[lv]:
            assert s['en'].lower().strip('.,?! ') not in ex, f'{tid}·{lv}: {s["en"]}'
print('✅ 规格与去重自检通过')
EOF
```

然后照常:`splice → burn → npm run validate → rsync iOS → 构建装机 → web 部署`。

## 五、审核流程(缺一轮就漏)

四轮都不是白跑的,各有各的强项:

| 轮 | 审校 | 强项 |
|---|---|---|
| 1 | v4pro(DeepSeek reasoner) | 重复检测、地道性、中式英语 |
| 1 | Codex(GPT) | **美国真实流程、安全责任、本地化细节**,会给官方链接佐证 |
| 2 | v4pro 复核 | 抓修订残留 |
| 3 | Codex 终审 | **抓修复时引入的新矛盾** |
| 4 | 多视角对抗验证(Workflow) | 事实/安全/一致性/地道性/教学梯度五路并行 |

**铁律**:凡涉及美国流程、法律、医疗的内容**必须过 Codex**——v4pro 语言好但不掌握这些事实。反过来重复检测 v4pro 更敏感。两家缺一不可。
