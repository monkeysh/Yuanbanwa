当前公开体验版

隐私政策

更新日期：2026 年 7 月 11 日

本政策说明“原版娃口语”当前公开体验版如何处理信息。核心原则是：体验状态和学习进度留在你的浏览器本地，当前版本不提供正式账号注册或服务端同步。

简要说明：可选昵称、本地体验标记、主题偏好和练习进度存于 localStorage；当前版本没有正式账号同步。使用跟读识别时，浏览器或操作系统提供的语音服务可能处理音频或转写。

一、保存在当前设备的信息

为了保持体验连续，页面会通过浏览器 localStorage 保存：

  • 主题偏好，例如浅色、深色或跟随系统；
  • 本地体验状态，包括你自愿填写的可选昵称、进入时间和页面生成的体验标记；
  • 学习进度，例如练习日期、完成句数、完成或常练场景、连续学习统计和复练队列。

这些信息不会在当前版本中同步到正式用户账号，也不会跨浏览器或跨设备自动迁移。当前页面不会把语音原始录音或识别文本写入上述本地学习记录。

二、体验身份与账号同步

当前版本不要求注册正式账号或提交登录身份资料。你可以不填写昵称；若填写，昵称与体验标记只在当前浏览器中保存和读取，不会作为登录请求发送到业务服务端。

因此，当前体验入口不等同于正式账号认证，也不能用于跨设备同步或找回学习记录。

三、麦克风与语音识别

当你主动点击跟读并允许麦克风权限时，页面会调用浏览器的 Web Speech API 获取英文转写，用于本次页面内的词级匹配和练习反馈。

  • 麦克风权限由浏览器或操作系统管理，你可以在设备设置中随时撤回。
  • 不同设备可能使用 Apple、Google 或其他由浏览器／系统指定的语音服务。音频、转写和相关技术信息可能被发送给该服务处理，具体以你的浏览器、操作系统和语音服务提供方规则为准。
  • 当前网站不主动把原始录音保存为音频文件，也不将识别文本同步到正式账号。

如你不希望第三方语音服务处理音频，请不要授予麦克风权限；你仍可浏览文字内容和播放示范音频。

四、提供页面所需的网络连接

本站托管

浏览器会请求页面、场景数据、图片和示范音频。与一般网站相同，托管服务器可能在访问日志中记录 IP 地址、访问时间、请求路径、浏览器或设备类型等基础技术信息，用于安全、故障排查和服务运行。

生产静态资源

正式上线页面所需的程序、图片、数据和示范音频由本站托管。当前版本未接入广告或行为画像功能。开发预览环境只用于本地测试，不构成线上产品的数据处理说明。

五、保存期限与删除方式

localStorage 中的数据会保留到你主动退出相应本地状态、清除本站数据，或浏览器／系统自行清理为止。你可以通过浏览器的“网站数据”“存储”或“隐私”设置删除本站本地数据；删除后当前版本无法恢复。

如果你希望咨询托管访问日志等非本地信息，请通过你获得本产品链接的原渠道，联系向你提供体验入口的老师或运营方。

六、未成年人

本产品可能由未成年人用于学习。监护人应协助未成年人理解本政策、决定是否使用语音识别，并管理麦克风及浏览器网站数据。请不要在页面中输入与学习无关的敏感个人信息。

七、更新与联系

如后续接入正式短信、服务端账号、云同步、付费服务或新的语音评测服务，我们会在启用前更新本政策，并说明新增的数据用途和控制方式。

如有问题、反馈或个人信息相关请求，请沿用你获取体验链接的原联系渠道；当前页面不编造未经确认的邮箱、电话或主体信息。

使用本产品也请阅读《用户协议》。
